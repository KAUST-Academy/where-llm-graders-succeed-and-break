# Exam Guidelines

## Theory Exam

- **Closed book:** The exam is closed book.
- **Number of questions:** There are 67 questions in the exam and only one correct answer for each.
- **Calculator:** No calculators are allowed in the exam.
- **Time:** The exam is going to run for 2 hours. You cannot enter the exam if you come after 30 minutes late. You cannot leave the exam hall unless half the time is over.

---

## Practical Exam

### Allowed Resources

- **Slides, Labs & Exercises' Official Solutions:** All official materials provided during the stage from the academy.
- **Personal Notes:** Non-code notes only (e.g., comments written in the labs by the student, PDF summarizing the functions in each lab, PDF for practical configurations choices).
  - *Exception:* It is allowed to use a notebook to collect/organize codes copied from the labs.
- Your practical exam solution should consist **ONLY** of codes copied/modified from the official labs/exercises **OR** written by you during the exam.

### Prohibited Items

- **Pre-written Code:** Codes written prior to the exam (this includes: any AI/non-AI generated codes outside the labs/exercises, exercises solutions written by students, any prewritten function/dataset class outside the labs).
- **AI Tools:** No use of AI-assisted tools (ChatGPT, Gemini, etc.).

### Exam Structure

The exam consists of **four questions in 3 hours**.

#### Questions 1 (12 marks, 4 bonus), 2 (11 marks, 4 bonus), and 3 (12 marks)

- **Base Tasks:** Apply lab logic to new datasets or configurations.
- **One Bonus Task:** A challenging extension of lab concepts.

#### Bonus Question 4 (5 marks)

- **Optional Bonus:** An additional, entirely optional problem.

> **Note:** Model accuracy doesn't matter as long as it is not been asked explicitly in the task. You will be evaluated only on successfully coding and running the task.

### Grading Criteria (per task in each question)

| Score | Definition |
|-------|------------|
| **100%** | Code runs perfectly, produces the correct output, and follows optimal logic. |
| **25%–75%** | *Partial Credit:* The code is generally correct but contains syntax errors or logical mistakes. |
| **0%** | No code was submitted or written. |
| **-50%** | The code uses an entirely incorrect approach, is a blind copy-paste, or disregards specific instructions (e.g., using a different dataset). |

> **Note:** The bonus tasks/question don't have negatives. Also the 4th bonus question doesn't have partial grade (you get either zero or full).
